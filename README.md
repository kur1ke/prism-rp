# Prism RP 0.3.1

Среда для ролевой игры, где персонаж реагирует на сцену через стабильную личность (Card) и пережитый опыт (Experience). Ни один из этих слоёв не становится жёстким сценарием. Рутину — время, место, одежду, отношения — ведёт приложение.

Спецификация: документ «Prism RP — спецификация v1».

## Что нового в 0.3.1

- **Карточка по стандарту Character Card V2/V3 (как в SillyTavern).**
  - Поля и названия: Имя, Описание, Краткое описание личности, Сценарий, Первое сообщение, Альтернативные приветствия (каждое отдельным полем), Примеры диалогов, Системный промпт, Инструкции после истории, Заметки создателя, Теги, Создатель, Версия персонажа.
  - Рядом с подписью — ключ спецификации (`description`, `first_mes`…), видно, куда поле попадёт при экспорте.
  - Лорбук: название, порядок, основные и дополнительные ключи (выборочные записи), позиция до/после описания, постоянные записи, учёт регистра. Неизвестные поля записей сохраняются.
- **Редактирование легко найти:** кнопка «Изменить» на плитке персонажа, клик по имени или портрету в шапке чата, значок карточки в шапке.
- **LoRA только в карточке персонажа.** Общих LoRA в настройках больше нет. Настройки изображений (триггер, LoRA, гардероб) экспортируются внутри карточки в `extensions.prism_rp`.
- **Разметка на Perchance:** страница Perchance центрировала текст, из-за этого съезжали подсказки и галочки в настройках. Исправлено.

## Что было в 0.3.0 — изображения

**Чем рисовать** («Настройки → Изображения»):
- бесплатная генерация Perchance;
- ваш локальный Forge / A1111 / ReForge;
- любой OpenAI-совместимый API изображений.

**Когда рисовать.** Модель сама решает, когда показать картинку: пишет служебную строку `[draw: …]`, приложение её прячет и рисует сразу. Кнопка «Нарисовать» под любым ответом рисует этот момент вручную.

**Как собирается промпт.** Логика ваших модулей из форка перенесена и переписана под новую архитектуру:
- Сцена на русском переводится текстовой моделью в теги danbooru или в описание; перевод кэшируется.
- Неизменяемые теги идут в начало как есть, переводчик их не видит:
  - образ из гардероба персонажа по одежде из панели сцены («худи | hoodie: …»);
  - ваша внешность;
  - откровенные модификаторы — только по тексту сцены.
- Если сцена одевает персонажа иначе, чем записано в трекере, старый образ не добавляется («сцена важнее трекера»).
- Триггер, негатив и LoRA персонажа — только когда он в кадре.
- Закреплённый блок качества: свои теги качества модель тогда не пишет.
- Чистка промпта: повторы с триггером, лишние запятые, `solo` при двух людях.
- Вид от первого лица (POV): ваша внешность не добавляется, негатив против «лишних конечностей».

**Forge / A1111.**
- Загрузка списков с сервера: модели, VAE, сэмплеры, апскейлеры, LoRA.
- Hires fix.
- Размеры по обученным SDXL-бакетам, максимальная сторона.
- LoRA у каждого персонажа (в 0.3.1 общие убраны).
- Seed: случайный, закреплённый в настройках или закреплённый за персонажем кнопкой у картинки.

**У картинки:**
- кнопки «заново», «закрепить seed», «промпт и параметры», «скачать», «удалить»;
- просмотр на весь экран.

**Персонаж и вы.**
- В карточке появился раздел «Изображения»: триггер, другие имена, стилевые теги, негатив, LoRA, seed, внешность, гардероб, откровенные модификаторы.
- В разделе «Вы»: ваша внешность для картинок и выбор «со стороны / от первого лица».

### Подключение Forge / A1111

1. Запустите сервер с флагами `--api --cors-allow-origins=*`. Можно указать точный адрес вместо `*`: приложение показывает его в подсказке под полем адреса.
2. «Настройки → Изображения → Forge / A1111 / ReForge», адрес `http://127.0.0.1:7860`.
3. Нажмите «Проверить и загрузить списки» и выберите модель.

Браузер может спросить разрешение на доступ к локальной сети — разрешите. Если сервер занят (например, обучением LoRA), запрос вернёт ошибку. Приложение покажет её и не будет повторять запрос: сервер мог уже начать рисовать.

## Что было в М1

- **Чат-сцена**: дерево сообщений, свайпы, регенерация, правка, удаление ветки, рассуждение модели в свёрнутом блоке.
- **Режим «Мессенджер»**: переписка пузырями. Ответ режется на отдельные сообщения по пустым строкам. Статус персонажа берётся из сцены. Опыт общий с чатами-сценами этого персонажа.
- **Prism-сборщик**: Card подаётся как «склонности, не команды», опыт — как «свидетельства прошлого», сцена — как факты. Есть бюджет токенов, лорбук по ключевым словам и примеры речи. Вкладка **Prism** показывает, что именно ушло в модель.
- **Трекер сцены и гардероба**: модель присылает дельты `[scene: …]`, приложение их применяет и прячет из текста. Свайп или удаление откатывает и сцену. Сцену можно поправить вручную.
- **Опыт**: записи вида «событие / интерпретация / последствия», с темами, знаком, силой и источником. Отбор добирает противовес, чтобы одна травма не доминировала. Опыт принадлежит персонажу, а не чату.
- **Карточки**: импорт PNG/JSON (CCv1/v2/v3), редактор, лорбук, экспорт JSON и PNG без потери неизвестных полей.
- **Провайдеры**:
  - бесплатная модель Perchance (ai-text-plugin);
  - любые OpenAI-совместимые API (OpenRouter, DeepSeek и др.);
  - локальные LM Studio / Ollama / llama.cpp / KoboldCpp — работают в отдельной версии. На Perchance они станут доступны только при включённом на сервере CORS.
- **Бэкап**: один JSON со всеми данными. Через него же делается переезд.

## Установка на Perchance

Ставьте Prism RP в **новый** генератор, а не в форк URV, иначе код форка затрётся.

1. Войдите на perchance.org (кнопка `login` справа вверху) и нажмите `+ new` слева вверху.
2. **Верхнее левое окно с кодом** (поле Lists — там пишутся строки вида `{import:…}`): выделите всё (Ctrl+A) и вставьте содержимое `dist/perchance/lists.txt`.
3. **Нижнее правое окно с кодом** (поле HTML, под окном предпросмотра): выделите всё и вставьте содержимое `dist/perchance/html.html`.
4. Нажмите `save` справа вверху. Приложение появится в окне предпросмотра; бесплатная модель Perchance выбрана сразу.

Чат «AI helper» в левой колонке редактора для установки не нужен.

Код внутри `<script>` и `<style>` Perchance не обрабатывает. Сборка дополнительно проверяет, что в разметке вне них нет `[ ] { }`. Инструкция в ai-text-plugin передаётся функцией, поэтому скобки в карточках и сообщениях не раскрываются.

## Отдельная версия (для переезда)

`dist/standalone/index.html` — один файл, открывается двойным щелчком или с любого статического хостинга. Это тот же код, только без провайдера Perchance.

**Переезд**: на Perchance «Настройки → Скачать бэкап», в новой среде «Загрузить бэкап». Данные хранятся в IndexedDB того сайта, где открыто приложение, поэтому бэкап — единственный мост между платформами.

## Разработка

```
node tests/run.js                 # 48 юнит-тестов чистых модулей
node build.js                     # сборка dist/perchance и dist/standalone
python3 tests/e2e.py <папка>      # 75 сквозных проверок (с моком Forge/A1111) в headless Chromium (нужен playwright)
```

Исходники — классические скрипты без сборщика. Каждый модуль кладёт себя в `window.PRP`, поэтому один и тот же код работает на Perchance, с `file://` и в Node-тестах.

| Модуль | Назначение | Зависит от платформы |
| --- | --- | --- |
| `js/core/util.js` | id, экранирование, макросы `{{char}}/{{user}}`, оценка токенов | нет |
| `js/core/store.js` | IndexedDB: cards, chats, messages, experience, settings; бэкап | нет |
| `js/prism/scene.js` | протокол дельт, свёртка сцены, описание для модели | нет |
| `js/prism/experience.js` | записи опыта, отбор с противовесом | нет |
| `js/prism/assembler.js` | Prism-сборщик: слои, подача, бюджет, режимы rp/messenger | нет |
| `js/cards/ccard.js` | CCv1/v2/v3, чтение и запись PNG-чанков | нет |
| `js/chat/tree.js` | дерево сообщений и ветки | нет |
| `js/providers/openai.js` | OpenAI-совместимый стриминг, повторы, диагностика CORS | нет |
| `js/providers/perchance.js` | адаптер ai-text-plugin | **да**, только Perchance |
| `js/images/compose.js` | промпт изображения: гардероб, внешность, POV, присутствие, чистка тегов, размеры, `[draw:]` | нет |
| `js/images/compile.js` | перевод сцены в промпт текстовой моделью, кэш | нет |
| `js/images/backends.js` | Perchance `image()`, Forge/A1111, OpenAI-совместимые | Perchance — только на Perchance |
| `js/ui/render.js` | иконки, портреты-заглушки, разметка прозы | нет |
| `js/ui/views.js` | все экраны как чистые функции «состояние → HTML» | нет |
| `js/ui/app.js` | состояние, действия, генерация, события | нет |
| `css/app.css` | дизайн-система и три темы | нет |

Привязка к Perchance — один файл-адаптер плюс одна строка импорта в Lists. Всё остальное переезжает без изменений.

Шрифты подгружаются с Google Fonts; без сети используются системные шрифты.
